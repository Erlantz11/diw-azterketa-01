# Azterketa egiteko

Egin beharrekoa:

1. Joan behar zara hurrengo GitHub-eko repositoriora: 
2. Egin ezazu “*fork*” zure erabiltzailearekin
3. Jeitzi **ZURE** repositorioa
4. Ariketa bakoitzak bere karpeta dauka
   - ezin dituzu HTML fitxategiak ikutu
5. Amaieran: commit, push eta pull-request egin behar didazu.

Ariketa bakoitzean egin beharrekoa daukazu eta irudi bat amaiera nola izan behar den. **Respositorioan ere daude ariketen azkeneko itxuraren irudiak**.
