# Ariketa 05

Eman dizute webgune bat akats batzuekin. Konpondu daukazun CSS hurrengo kontutan hartuta:

- CSS-an dauden kolore guztiak aldagaietan jarri eta erabili. (**0,25 puntu**)
- Goiburua 
  - Goialdean finko mantendu behar da orrian behera mugitzean (**0,25 puntu**)
  - Carritoren zenbakia borobil laranja (**#ff9a67**) batean jarri. (**0,25  puntu**)
  - Aldatu markaren izenaren koloreak (**0,25 puntu**)
- Erosteko botoia:
  - Aldatu irudian agertzen den bezala (**0,25 puntu**)
  - Botoia goian jartzen denean botoiaren kolorea aldatu. (**0,25 puntu**)
- Mahaigaineko pantailan:
  - erakutsi irudia eta produktuaren informazioa bi zutabetan, Grid erabiliz. (**0,5 puntu**)
- Prezioa eta valoraciones:
  - Prezioaren itxura zuzendu (**0,25 puntu**)
  - Balorazioen izarrak laranjak jarri eta textua txikiago jarri eta grisez. (**0,25 puntu**)
- 760 px baino gutxiagoko pantailatan:
  - antolatu irudia eta informazioa zutabe bakarrean. (**0,25 puntu**)
  - goiburuan kendu "nav" (**0,25 puntu**)


- irudia dago: img/producto.webp
